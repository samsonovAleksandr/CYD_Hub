# Мост: компьютер → CYD Hub

В папке два независимых моста. Одновременно запускается только один — источник
лимитов выбирается в `/admin` → «Источник лимитов».

| Скрипт | Что даёт | Режим |
|---|---|---|
| `codex_cyd.py` | лимиты подписки **Codex** | по умолчанию |
| `claude_cyd.py` | сессии и разрешения Claude Code, лимиты Claude, музыка | старый режим → [README_CLAUDE.md](README_CLAUDE.md) |

## Codex: лимиты подписки (по умолчанию)

`codex_cyd.py` читает лимиты через локальный `codex app-server` и отправляет их
в существующий API Hub `POST /usage`. Плату перепрошивать не нужно.

Мост не вызывает модель, не читает `auth.json` напрямую и не устанавливает хуки.
Используется вход в ChatGPT, уже выполненный в Codex. Это не лимиты OpenAI API.
Официальный протокол: [learn.chatgpt.com/docs/app-server](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt).

Нужен Python 3.9+ и установленный Codex с выполненным входом.

### Установка

1. В `/admin` выберите источник **Codex** и скопируйте готовую команду с адресом и токеном.
2. Проверьте вход и лимиты, ничего не отправляя:

   ```bash
   codex login status
   python bridge/codex_cyd.py status
   ```

   Если Codex не найден в `PATH`, добавьте `--codex "C:/полный/путь/codex.exe"`.

3. Установите настройки и отправьте первый замер:

   ```bash
   python bridge/codex_cyd.py install --url http://<адрес-сервера>:8770 --token <токен>
   python bridge/codex_cyd.py watch
   ```

   `install` проверяет Hub и Codex, отправляет первый замер и сохраняет настройки
   в `$CODEX_HOME/cyd.json` (по умолчанию `~/.codex/cyd.json`). Фоновый процесс он
   не запускает. `watch` обновляет лимиты раз в 60 секунд, Ctrl+C останавливает.
   Для другого пути настроек задайте `CODEX_CYD_CFG`.

4. Если раньше использовался мост Claude, уберите его наблюдатель из автозагрузки:
   `python bridge/claude_cyd.py desktop-off`. Уже работающий процесс эта команда не
   завершает — выйдите из Windows и войдите снова либо завершите процесс
   `claude_cyd.py watch`. В режиме Codex сервер отклоняет данные старого моста,
   поэтому два наблюдателя не смогут подменять проценты.

Запуск без видимого окна (PowerShell):

```powershell
Start-Process -WindowStyle Hidden -FilePath python -ArgumentList 'bridge/codex_cyd.py', 'watch' -RedirectStandardOutput bridge/codex-watch.log -RedirectStandardError bridge/codex-watch-error.log
```

Автозагрузка настраивается в Планировщике заданий Windows: запускать Python
с аргументами `bridge/codex_cyd.py watch` при входе **того же пользователя**.
Второй экземпляр обнаружит занятый локальный порт 47322 и завершится.

### Команды

| Команда | Что делает |
|---|---|
| `status` | показать текущие лимиты, ничего не отправляя в Hub |
| `once` | прочитать лимиты и отправить один замер |
| `test` | проверить доступность Hub и токен |
| `watch --interval 120` | другой период, минимум 30 секунд |
| `--limit-id codex` | выбрать конкретную группу квот; неизвестная группа даёт ошибку |

Параметр `--limit-id` можно сохранить командой `install`. Музыка в режиме Codex
не передаётся: для неё нужен старый мост Claude.

### Что видно на экране

Проценты означают **израсходовано**, а не «осталось». Время сброса приходит от
Codex и не вычисляется по истории. Пятичасовое и недельное окна определяются по
длительности, а не по порядку `primary` / `secondary`. Если аккаунт отдаёт только
неделю, на экране будет одно кольцо. Другие длительности тоже показываются, но
графики и прогноз доступны только для 5 часов и недели. Пустой ответ об окнах
означает отсутствие данных, а не безлимитный тариф.

При недоступности Codex или сети последние цифры остаются с прежним временем
замера и затем помечаются как устаревшие. Мост повторяет подключение. Нулевые
значения при ошибке не придумываются. История в Hub хранится в памяти.

**Граница интеграции:** мост передаёт только лимиты. Он не подписывается на чужие
чаты Codex и не принимает разрешения с платы. Сессии, ответы и подтверждения
действий остаются в приложении Codex.

## Claude Code (старый режим)

Полная инструкция: [README_CLAUDE.md](README_CLAUDE.md). Кратко:

```bash
python bridge/claude_cyd.py install --url http://<адрес-сервера>:8770 --token <токен>
python bridge/claude_cyd.py demo
```

Скрипт дописывает хуки и статусную строку в `~/.claude/settings.json`, запускает
наблюдатель и умеет музыку Windows. После установки перезапустите сессии Claude
Code и включите источник **Claude** в `/admin`.

## Проверка разработки

```powershell
python -m unittest discover -s bridge/tests -v
node bridge/tests/test_screen.cjs
```

Тесты используют искусственные ответы Codex, локальный HTTP-сервер и отдельный
процесс для проверки протокола, таймаутов, завершения, недельного окна без
пятичасового и защиты от старого наблюдателя. `status` проверяет настоящий
аккаунт отдельно.
