# Мост: компьютер → CYD Hub

`claude_cyd.py` запускается на компьютере, где вы работаете, и отправляет в CYD Hub всё, что нужно для вкладок **Claude** и **Музыка**:

- **Сессии Claude Code.** Над чем работает каждая сессия: «работает», «ждёт ответа» или «готово». Тап по карточке открывает запрос, последние действия (до 8) и последний ответ. Когда сессия закончила, плата пищит.
- **Разрешения с экрана.** Когда Claude просит разрешения (запустить команду, изменить файл), запрос появляется на экране с кнопками **Разрешить / Запретить / Всегда / В терминале**. Плата пищит и мигает фиолетовым.
- **Лимиты.** Сколько израсходовано за 5 часов и за неделю и когда счётчики сбросятся. Источник — статусная строка `claude` в терминале или файл Claude Desktop (см. ниже). Есть только у подписок Pro/Max.
- **Музыка.** Что играет на компьютере, с обложкой, и кнопки ⏮ ⏯ ⏭ (только Windows).

Нужен Python 3.9+. Для Claude Code и лимитов хватает стандартной библиотеки. Компьютер и CYD Hub должны быть в одной сети.

## Установка

1. Откройте `/admin` вашего CYD Hub, в разделе «Подключение» скопируйте готовую команду с адресом и токеном. Она выглядит так:

   ```bash
   python bridge/claude_cyd.py install --url http://192.168.1.10:8770 --token ABCD2345
   ```

   Скрипт проверит связь, сохранит адрес в `~/.claude/cyd.json` и допишет хуки и `statusLine` в `~/.claude/settings.json`. Старая версия файла сохранится в `settings.json.bak`. Если `statusLine` у вас уже свой, скрипт его не трогает и подскажет, что добавить.
2. Проверка кнопок без Claude:

   ```bash
   python bridge/claude_cyd.py demo
   ```

3. Перезапустите сессии Claude Code: новые настройки подхватываются при старте.

Удалить: `python bridge/claude_cyd.py uninstall`.

## Лимиты без терминала (Claude Desktop)

Десктопное приложение пишет замеры лимитов в `plan-usage-history.json` (на Windows: `%LOCALAPPDATA%\Claude-Data\<id>\`). Фоновый наблюдатель читает этот файл раз в минуту и отправляет новые цифры в хаб. Идею подсмотрели в проекте [Blink](https://github.com/KfirLevy258/Blink).

```bash
python bridge/claude_cyd.py desktop-on
```

Команда запускает наблюдатель (`pythonw`, без окна) и кладёт `claude_cyd_watch.vbs` в автозагрузку Windows. `install` делает это сам. Убрать: `desktop-off`. Посмотреть, что видно в файле: `desktop`.

- **Какой источник показывается.** Экран показывает самые свежие данные: из терминала или из приложения. Под кольцами написано, откуда цифры и когда сделан замер; если данные устарели — как их обновить.
- **Время сброса.** В файле приложения его нет. Пятичасовое окно вычисляется по замерам (точность ±10 мин). Недельный сброс берётся из терминальной сессии (запоминается) и дальше отсчитывается по 7 дней.
- **Формат не документирован.** Новые версии приложения пишут файл реже (иногда только при запуске). Самые точные и свежие цифры дают сессии `claude` в терминале.

## Музыка (вкладка ♪)

Тот же фоновый наблюдатель раз в секунду смотрит, что играет на компьютере, и отправляет в хаб название, исполнителя, обложку и позицию. Данные берутся из Windows (как на панели громкости), поэтому подходят Яндекс Музыка в приложении и в браузере, Spotify, YouTube и другие плееры. Кнопки на экране управляют плеером на компьютере.

Нужны пакеты Python:

```bash
pip install winrt-runtime winrt-Windows.Media.Control winrt-Windows.Foundation winrt-Windows.Foundation.Collections winrt-Windows.Storage.Streams
```

Проверить, что видит мост: `python bridge/claude_cyd.py media`. Вкладка ♪ появляется на экране, пока что-то играло за последние 10 минут. Музыку с телефона или умной колонки так не увидеть. После установки пакетов перезапустите наблюдатель (`desktop-on` или перезагрузка).

## Как работает ответ с экрана

Хук `PermissionRequest` отправляет запрос в хаб и ждёт нажатия (по умолчанию до 90 с, меняется через `--wait`).

| Кнопка | Что происходит |
|---|---|
| Разрешить | Claude выполняет действие |
| Запретить | Claude получает отказ и продолжает работу без этого действия |
| Всегда | Разрешить и добавить правило, которое предложил Claude Code (например, «всегда разрешать `npm test`»). Кнопка есть, только если правило было предложено |
| В терминале / таймаут / хаб недоступен | Хук не принимает решения, вопрос задаётся как обычно в Claude Code |

Если ответить в терминале раньше, запрос пропадёт с экрана, как только инструмент выполнится.

> Пока хук ждёт кнопку, диалог в терминале может не показываться: так устроены хуки Claude Code. Если вы сидите за компьютером, нажмите на экране «В терминале» или уменьшите `--wait`.

## Команды

| Команда | Что делает |
|---|---|
| `install --url … --token … [--wait 90]` | прописать хуки и статусную строку, запустить наблюдатель |
| `test` | проверить связь с хабом |
| `demo` | тестовый запрос разрешения на экран |
| `desktop` | что видно в файле лимитов Claude Desktop (и отправить) |
| `desktop-on` / `desktop-off` | фоновый наблюдатель (лимиты Desktop + музыка) и его автозапуск |
| `media` | что сейчас играет (и отправить) |
| `uninstall` | убрать всё из `settings.json` |

Отладка: создайте файл `~/.claude/cyd_debug` — всё, что Claude Code передаёт хукам, будет писаться в `~/.claude/cyd_debug.log`.

## Безопасность

- Без токена хаб не принимает запросы. Токен хранится в `~/.claude/cyd.json`.
- Соединение идёт по обычному HTTP внутри домашней сети. Не пробрасывайте порт хаба в интернет.
- «Разрешить» на экране — то же самое, что Enter в диалоге. Читайте команду, прежде чем нажимать.
