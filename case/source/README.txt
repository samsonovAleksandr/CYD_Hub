ESP32 2432S028 CYD case by ghfisanotti on Thingiverse: https://www.thingiverse.com/thing:7047135

Summary:
This is a case for one of the "Cheap Yellow Display" boards that include a ESP32 micro controller along with a 2.8 display. I'm using it for a project involving ESPhome firmware with LVGL graphics library and integration into my Home Assistant installation.I've included two versions of the base part, one flat and minimal and one slanted 30 degrees that may make the display more readable.To assemble the base with the lid you'll 4x M3x10 screws with Allen heads, no inserts are required.
