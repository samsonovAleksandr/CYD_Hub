# Как помочь проекту

Спасибо, что заглянули! Баги, идеи и pull request'ы приветствуются.

## Как устроен код

| Где | Что |
|---|---|
| `server/app/main.py` | HTTP API (FastAPI): плата, мост, `/admin`, экран |
| `server/app/state.py` | настройки, темы, состояние Claude Code |
| `server/app/monitor.py` | проверки серверов, SSH, Docker, Wake-on-LAN |
| `server/app/render.py` | Chromium без окна → кадр RGB565 → изменившиеся плитки |
| `server/app/static/screen.html` | весь интерфейс платы |
| `server/app/static/admin.html` | страница настроек |
| `firmware/CYDView/app.cpp` | прошивка платы |
| `bridge/claude_cyd.py` | мост на компьютере |

## Разработка

- **Экран.** Удобнее всего править `screen.html` и смотреть результат в `/admin` (превью) или на `/screen` в окне 320×240. После правок: `docker compose up -d --build`.
- **Стиль кода.** Комментарии и интерфейс — по-русски, коротко и по делу. Новую зависимость добавляйте только если без неё никак (мост для Claude Code работает на стандартной библиотеке Python).
- **Секреты.** Никогда не коммитьте `server/data/`, `.env`, токены, IP-адреса и ключи своих серверов. Скриншоты для документации снимайте на демо-данных.
- **Проверка.** Опишите в PR, что проверили и на каком железе: на реальной плате, в превью или только сборка.

## Как прислать изменения

1. Сделайте fork и ветку от `main`.
2. Небольшие связные коммиты с понятным описанием.
3. Откройте pull request и опишите, что и зачем поменялось, приложите скриншот экрана, если менялся интерфейс.
