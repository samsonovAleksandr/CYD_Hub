# CYD Hub — сервер

Плата с прошивкой [CYDView](../firmware/CYDView) — это просто экран и тач. Всё остальное делает этот сервер:

- рисует экран: страница `/screen` 320×240 открыта в Chromium без окна, кадр переводится в RGB565 и отдаётся плате плитками 32×24, сжатыми zlib, — только изменившиеся;
- превращает касания платы в клики и прокрутку на этой странице;
- принимает события от моста [bridge/claude_cyd.py](../bridge): сессии Claude Code, ответы, лимиты, запросы разрешений, музыку;
- проверяет серверы (ping, TCP, HTTP), берёт нагрузку, список контейнеров Docker и выполняет команды по SSH;
- даёт страницу настроек `/admin`.

## Установка

```bash
cd server
cp .env.example .env      # ADMIN_PASSWORD — пароль для /admin (логин admin), TZ — часовой пояс экрана
docker compose up -d --build
```

Откройте `http://<сервер>:8770/admin`: добавьте серверы и команды, выберите стиль и посмотрите живой кадр экрана. Там же указан токен для платы и моста.

Обновление: `git pull`, затем снова `docker compose up -d --build`. Настройки лежат в `./data` и не теряются.

## Серверы

Для каждого сервера в `/admin` задаются адрес, проверки (ping, TCP-порт, HTTP URL), доступ по SSH (пароль или приватный ключ), иконка и важные контейнеры Docker.

- **Ключ для хаба.** Лучше завести отдельный ключ и добавить его публичную часть в `~/.ssh/authorized_keys` на серверах. Ключи серверов (`known_hosts`) запоминаются при первом входе.
- **Нагрузка** берётся из `/proc/loadavg`, `free`, `df` и `nproc`, root не нужен.
- **Docker.** Пользователю нужен доступ к `docker` (группа `docker`). Отмеченные «важные» контейнеры попадают на вкладку Docker; если работавший контейнер остановился или пропал, экран поднимает тревогу.
- **Статусы.** «OK» — все проверки прошли; «проблемы» — часть проверок не прошла, SSH недоступен или сервер перегружен (load > 1,5 на ядро, память или диск ≥ 90 %); «не отвечает» — не прошла ни одна проверка несколько раз подряд. Облачные серверы часто не отвечают на ping — тогда отключите эту проверку.

## Что на экране

- **Claude.** Кольца лимитов с прогнозом, источник цифр, статистика за день и сессии. Тап по кольцам — графики. Запрос разрешения показывает кнопки «Запретить / Терминал / Всегда / Разрешить».
- **Серверы.** Плитки с иконками (размер подбирается, чтобы все влезли на экран) или список с нагрузкой. Тап — подробности, графики CPU/RAM/диска за сутки, команды и контейнеры.
- **Docker.** Важные контейнеры всех серверов, упавшие сверху. Тап — логи, перезапуск, остановка.
- **Сводка.** Часы, погода (MET Norway), курсы ЦБ, кнопки Wake-on-LAN (пакет отправляется по SSH с выбранного сервера).
- **♪ Музыка.** Появляется, пока на компьютере что-то играет.
- **Заставка и яркость.** После простоя экран сам листает вкладки. Яркость — всегда максимум, ночью тусклее или по датчику света платы.

## Прошивка по Wi-Fi

Плата прошивается с разделом «Minimal SPIFFS (1.9MB APP with OTA)». Новую версию собирайте с тем же разделом (Arduino → «Экспорт бинарного файла») и загружайте `.bin` в `/admin`, раздел «Плата и прошивка». Плата сравнит md5, скачает файл, проверит его и перезагрузится. Неудачную версию второй раз она не пробует.

## API

| Путь | Кто вызывает | Что делает |
|---|---|---|
| `GET /api/frame?v=&t=` | плата | Долгий опрос до 15 с: отдаёт изменившиеся плитки кадра. Заголовки `X-Led`, `X-Beep`, `X-Wake`, `X-Dim`, `X-Off` управляют светодиодом, звуком и подсветкой |
| `POST /api/touch` | плата | `d x y` / `m x y` / `u x y`. Нажатие без движения — клик, движение — прокрутка |
| `/event`, `/perm`, `/usage`, `/ping`, `/state` | мост | Claude Code: события сессий, запросы разрешений, лимиты |
| `POST /media`, `GET /media/cmd` | мост | Музыка: что играет; длинный опрос нажатий кнопок |
| `/screen`, `/api/ui`, `/api/act` | Chromium внутри контейнера | Экран: HTML, CSS и JS в `app/static/screen.html` |
| `/admin`, `/api/config` | вы в браузере | Настройки, пароль из `ADMIN_PASSWORD` |

Мост и плата передают токен в заголовке `X-Token` или параметре `?t=`.

## Как менять

- **Дизайн экрана** — обычная веб-страница: правьте `app/static/screen.html` и пересоберите контейнер. Посмотреть её можно в браузере (`/screen`, окно 320×240) или на превью в `/admin`.
- **Стили.** 8 готовых: Ночь, Claude Code, Pixel Art, Star Wars, Матрица, Synthwave, Бумага, Nord. Описаны в `THEMES` в `app/state.py`, особые эффекты — в конце CSS в `screen.html`. Шрифты (Google Fonts, OFL) скачиваются при сборке образа.
- **Иконки серверов** — `app/static/icons.js`, общие для экрана и `/admin`.

**Данные** лежат в `./data`:
- `config.json` — серверы, команды, токен, тема; там же SSH-пароли и ключи;
- `known_hosts` — ключи серверов;
- `history.json` — графики за сутки.

Сессии, лимиты и музыка хранятся только в памяти. После перезапуска контейнера мост пришлёт их заново.

## Ограничения

- После касания новый кадр приходит примерно через 0,2–0,4 с. Плата рисует кружок на месте нажатия сразу.
- Кадров примерно 4 в секунду, анимации дёрганые.
- Без сервера плата показывает только «Нет связи с сервером».
