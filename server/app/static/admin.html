CYD Hub

Настольный экран: Claude Code, серверы, команды. Всё, что на экране, настраивается здесь.

Стиль экрана

Готовый стиль, потом любые цвета поверх. Превью справа меняется сразу, плата — через секунду.

Серверы

Кнопки-команды (SSH, одни для всех серверов, до 6)

«Подтверждать» — экран переспросит перед запуском.

Проверки и экран

Яркость

Датчик сейчас показывает —. Накройте плату рукой и запишите число в «в темноте», уберите руку — в «при свете».

Сводка: погода, курсы, включение компьютеров

Wake-on-LAN

Кнопки «включить» на вкладке «Сводка». Пакет отправляется с выбранного сервера по SSH (он должен быть в той же сети).

Плата и прошивка

—

Новая прошивка по Wi-Fi: выберите .bin (Arduino → «Экспорт бинарного файла», раздел «Minimal SPIFFS»). Плата скачает её сама и перезагрузится.
