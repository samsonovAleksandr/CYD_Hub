# Изменения

## 0.1.0 — первая публичная версия

- Экран Claude Code: сессии, ответы, разрешения с экрана, лимиты с прогнозом и указанием источника.
- Серверы: ping / TCP / HTTP, нагрузка и графики по SSH, плитки с иконками и автоподбором размера, команды.
- Вкладка Docker: важные контейнеры всех серверов, тревога при падении.
- Вкладка «Музыка»: что играет на компьютере с Windows, обложка, кнопки управления.
- Сводка: погода, курсы ЦБ, Wake-on-LAN.
- 8 тем, настройка цветов, шрифта и скругления в `/admin`.
- Прошивка CYDView с настройкой через точку доступа и обновлением по Wi-Fi.
- Настольный корпус с подставкой.
